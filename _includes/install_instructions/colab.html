Python (via Google Colab)

Python is a popular language for research computing, and great for general-purpose programming as well. For this workshop we will write and run Python in Google Colab, a free notebook environment that runs entirely in your web browser — no installation is required.

To get ready, please do the following before the workshop:

  1. Make sure you have a Google account (a free personal account is fine).
  2. Go to https://colab.research.google.com/ and sign in with your Google account.
  3. Create a new notebook (File → New notebook), type print("Hello, world!") in a cell, and press Shift+Enter to check that it runs.

If you cannot access Google Colab (for example, if it is blocked on your network), please contact the workshop organizers before the workshop so we can help you find an alternative.
