# Software Carpentry Workshop — Northern Arizona University (Online)

Website for the online Software Carpentry workshop hosted by Northern Arizona University,
October 15–16, 2026 (9:00 am – 4:30 pm Arizona time).

**Workshop website:** <https://nilablueshirt.github.io/2026-10-15-nau-online/>

## Curriculum

- Day 1: [The Unix Shell](https://swcarpentry.github.io/shell-novice/) and [Version Control with Git](https://swcarpentry.github.io/git-novice/)
- Day 2: [Plotting and Programming in Python](https://swcarpentry.github.io/python-novice-gapminder/) (taught using [Google Colab](https://colab.research.google.com/))

This website was built from [The Carpentries workshop template](https://github.com/carpentries/workshop-template).
